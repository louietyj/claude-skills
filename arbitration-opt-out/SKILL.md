# arbitration-opt-out

## 1. Read the clause

Extract the document's own name for itself, the method (email / web form / mail, and where to), exactly what info the notice must contain, and any deadline. A lapsed deadline is worth flagging but not a reason to stop — updated terms often restart the window.

## 2. Check for a prior opt-out

Search with the company name and brand/parent variants:

- **Gmail**: his sent mail, plus the company's confirmation replies.
- **Dropbox `/Sent Mail`** (read only): mailed pieces are named `YYYY-MM-DD - <Company> - Arbitration opt-out…`.

A match for the same agreement → stop and tell him. A match under a different or older agreement (e.g. card agreement vs app ToS) may not cover this one → say which and let him decide.

## 3. Fill the template

Change only what the clause requires. No rewording, no added legalese, no polish-message — this is already his voice.

```
Hello,

As per the [document name], I would like to opt out of the arbitration agreement.

[Required info, one line per item]

Please reply to confirm that my request has been received and processed. I can be reached at louietyj@gmail.com or (415) 630-7551.
```

Default info lines — add/drop to match what the clause asks for:

```
Full name: Louie Yi Jie Tan
Mailing address: 609 San Conrado Ter Unit 1, Sunnyvale, CA 94085
Email address: louietyj@gmail.com
```

Anything required that you don't have (account number, username…): `[TODO]` line and ask; never guess. If the clause mandates specific wording or a signature, honour it.

## 4. Deliver

- **Email**: Gmail draft to the opt-out address, subject `Arbitration opt-out`. Create it last (it needs his approval); never send.
- **Web form**: text to paste, plus the form URL.
- **Mail**: text in a code block plus the recipient address; ask letter or postcard, and offer `usps-ops` to build it. The text he approved here is the message usps-ops would draft with him — don't redraft it. Subject in the file name: `Arbitration opt-out`.

End with one line on the deadline, if any.
